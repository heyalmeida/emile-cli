Como funciona

Do prompt à ação no projeto.

O Emile mantém uma conversa com modelos de IA compatíveis com a API OpenAI e usa ferramentas locais para inspecionar e alterar o workspace de forma controlada.

1

Você envia um prompt

Pode iniciar pela CLI com um comando ou abrir uma sessão interativa e conversar como faria com um colega.

2

O agente planeja e usa ferramentas

Emile lê o projeto, escolhe ferramentas, executa comandos, cria ou edita arquivos e mostra diffs no terminal.

3

O resultado fica salvo

Conversas são armazenadas em histórico local para continuar sessões, revisar decisões e retomar contextos.

Recursos principais

Projetado para desenvolvimento real.

O projeto combina automação de arquivos, suporte a modelos externos, habilidades especializadas e MCP em um fluxo de terminal simples.

Requesty e OpenRouter

Configuração flexível de provider e modelo via wizard interativo.

Prompt caching

Cache automático no Requesty para reduzir repetição em sessões longas.

Reasoning effort

Controle de esforço de raciocínio: low, medium, high, max e outros.

Plans mode

Fluxo com aprovação antes de executar planos e acompanhar tarefas.

Skills

Instruções especializadas por domínio: frontend, backend, testes, segurança e mais.

MCP

Conecta servidores MCP e expõe ferramentas externas ao agente.

Ferramentas locais

O agente pode agir no workspace.

As ferramentas internas permitem inspeção e alteração de arquivos com diffs visíveis no terminal.

readFile

Lê arquivos do projeto para entender estrutura, código e configurações.

writeFile

Cria ou sobrescreve arquivos, exibindo um diff da mudança.

editFile

Substitui blocos exatos de conteúdo para edições pontuais.

listDir

Lista arquivos e diretórios para navegação no projeto.

runCommand

Executa comandos no terminal do workspace para validar mudanças.

MCP tools

Ferramentas de servidores externos são chamadas com prefixo de servidor.

Uso rápido

Execute como CLI.

O pacote expõe o binário emile e também pode ser iniciado via script do npm.

terminal bash 
# Instalar dependências
npm install

# Iniciar o CLI
npm start

# Ou usar diretamente, se o pacote estiver linkado
emile "Crie uma página HTML com Tailwind sobre o projeto"

# Usar modo de planos
emile --plans "Refatore a arquitetura de ferramentas"

# Selecionar habilidades específicas
emile --skills clean-code,testing-patterns "Adicione testes"

Arquitetura

Um loop simples, extensível e observável.

CLI

Recebe prompts, comandos, histórico e opções de execução.

→

Agent

Monta system prompt, chama o modelo e processa tool calls.

→

Tools + MCP

Executa ações locais e ferramentas de servidores MCP conectados.

API compatível

Usa a biblioteca OpenAI com baseURL configurável para Requesty ou OpenRouter.

Skills compiladas

Carrega SKILL.md do workspace e injeta instruções relevantes no prompt do sistema.

Histórico local

Salva sessões com resumo para alternar, limpar ou retomar conversas.

Pronto para usar o Emile?

Configure sua chave de API, escolha o modelo e peça tarefas diretamente no terminal. O Emile cuida do contexto, das ferramentas e do histórico da sessão.

Começar rápido

  1. 1. Rode npm start.
  2. 2. Use /connect para configurar a API.
  3. 3. Envie um prompt ou use --plans.
