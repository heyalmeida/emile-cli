emile-cli

CLI Premium de Desenvolvimento Usando IA e ModelContextProtocol

\u2192 Documentação

Desbloqueie seu productive com inteligência avançada v1.0.0

Ferramenta de linha de comando que otimiza workflows de programação com modelos de IA via API Requesty, com caching de prompts, controle de esforço e integração com MCP.

\u2192 Instalar com npm \u25B6 Ver Demonstração

Funcionalidades Principais

Prompt Caching

Reduz custos e acelera execuções com cache inteligente de prompts repetidos.

Planos EMILE

Organize projetos complexos com estruturas lógicas e planejamento automático de etapas para desenvolvimento eficiente.

Integração MCP

Suporte direto ao protocolo ModelContextProtocol para fluxos sincronizados entre ferramentas e modelos de IA.

Habilidades Personalizáveis

Extensibilidade via plugins para funcionalidades customizadas como linting, formatação e execução de comandos.

Instalação

\u00b1 Instale globalmente com npm:
npm install -g emile-cli

\u00b7 Inicie com:
emile "Descreva sua tarefa"

\u00b7 Recomendações: node >= 16.0.0, npm >= 8.0.0

Exemplos de Uso

Comando Básico

emile "Crie um servidor REST em Node.js"

Este comando cria um servidor REST completo com Express e rotas pré-definidas.

Modo Alta Profundidade

Use o parâmetro -e high para obter raciocínio detalhado e explicações passo a passo durante o desenvolvimento.

Modo Plano

Use -p para dividir projetos grandes em etapas menores e bem organizadas.

Documentação

A documentação completa está disponível em docs/implementation_plan.md. Inclui guias de instalação, exemplos de código e explicações detalhadas sobre todas as funcionalidades do emile-cli.
